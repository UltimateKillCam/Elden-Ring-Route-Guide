# Desktop host

Run `scripts\build-desktop-host.ps1` after changing the C# host. Start the guide with
`desktop\runtime\Tarnished Together.exe`. The host opens the controller in a native
WebView2 window and keeps the same LAN follower support. Other players open the address
shown inside the app and enter its six-digit join code.

The Microsoft Edge WebView2 runtime and Node.js are required. Both are already present
on the machine this personal build was produced for.
